解决 MAC 笔记本 Stable Diffusion 安装时报 No matching

Mac 上安装 Stable Diffusion 卡在 No matching distribution found for tb-nightly？问题出在 pip 源缺少依赖包，换一个镜像源即可解决。

S
shark1357 · 原文作者2026.11.20 · 原文摘录 · 1 min read

本文整理自 CSDN 博主 shark1357 的排错记录，版权归原作者所有。查看原文。命令保留原样，方便直接复制执行。

00 / 问题定位

安装时重点看这个报错：

No matching distribution found for tb-nightly

这个错误说明，我们的 pip 源中没有对应的 tb-nightly 依赖包。

01 / 查看 pip 配置

先查看 pip 的配置：

pip config list

看到配置如下：

global.index-url='https://pypi.tuna.tsinghua.edu.cn/simple'

这说明使用的清华 pip 源中缺少 tb-nightly 这个包。那我们就换个阿里的源。

02 / 更换镜像源

使用如下命令切换为阿里源：

pip config set global.index-url https://mirrors.aliyun.com/pypi/simple

再来查看：pip config list，配置已经变成阿里的地址了：

global.index-url='https://mirrors.aliyun.com/pypi/simple'

03 / 重新安装

重新执行安装：

./webui.sh

即可顺利完成安装。
